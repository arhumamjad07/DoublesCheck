# Changelog

## Demo 1 — 24 October 2026

Initial public source milestone; implementation and its first recorded
verification were completed on 23 October 2026. Git commit: `demo 1`. Tag: `demo-1`.

### Included

- Local GUI and CLI for building/reviewing six-member historical VGC teams from
  one to six locked favourites.
- Real public Dex/usage data, explicit sample mode and a local Zetaris SQL join.
- Schema-2 snapshot: 1,417 species/form records, 358 usage rows and 11,376
  independently set-validated options across 357 supported species/forms.
- Bounded contextual search with full-set deduplication and source-aware scoring.
- Independent team legality, remembered avoidance and refusal of invalid results.
- Actual stats, EV/nature explanations, conditional Speed, interaction checks,
  possible opening actions and four-of-six practice plans.
- Real Meterless H-MEM with pinned upstream source and conformance checks.
- Reports, Showdown export, run traces, progress and project-status GUI.
- Public setup, architecture, data, operations, development and milestone guides.
- A deliberately public sample generated with isolated temporary memory.

### Verified

73 application tests and 13/13 H-MEM conformance checks passed. Selected mechanics
were checked against Showdown arithmetic and running local simulator fixtures.
Local Zetaris reconstruction matched the sample, and the connected build and GUI
HTTP form/report/progress flow passed. Visual browser review is not claimed.

### Known limitations

Cloud model calls are disabled in the main product. Nightshift AI integration,
current-2026 rules, damage simulation, optimized IVs and opponent-specific solving
remain unfinished. No best-team, win-rate, production-readiness or complete
hackathon-eligibility claim is made. See the roadmap and verification notes.
