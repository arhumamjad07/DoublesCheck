Strengthens live reliability, actual Critic-driven repair and varied user cases.
Commit: `Demo 3: verified AI reasoning and recovery`. Milestone tag: `demo-3`.
The `demo-1` and `demo-2` tags remain unchanged. Publication checks include a
fresh audit of both previous milestones and the exact staged release.

- Critic-first review dynamically invokes the Planner when evidence needs a change.
- Named revision contracts refuse unrelated edits; roles share source options.
  Each edit validates the full team and returns fresh versioned evidence.
- Manual continuation preserves completed work and lifetime budgets after an
  interruption; changed preferences, expiry and duplicate continuation are checked.

  and actual model/timing records. No automatic transport retry or provider fallback.
- `reliable` objective, honest unmet-goal alternatives and prepared-team review.
- Thirteen declared acceptance cases separate real model approvals, offline checks,
  expected input refusals and failures. Public examples show real repair/recovery.
- Invalid preferences are checked before memory writes; exact item matching fixes
  a feasible six-favourite team previously pruned from the local search.
- 154 application tests and 13/13 H-MEM checks; live results and limitations are
  recorded separately in `VERIFICATION.md`.

## Demo 2 — 24 October 2026

Adds an explicitly selected Nightshift/NVIDIA coach to the existing local product.
Git commit: `demo 2`. Milestone tag: `demo-2`.

- Nemotron Planner/Builder chooses whitelisted tools, team/set changes and checked
  evidence; a separate Critic role may block, require revision or approve.
- Versioned full-set fingerprints, issued set IDs, unchanged-team detection,
  original preferences and final independent legality remain code-enforced.
- Streaming transport supports Nightshift's preliminary alias frames and requires
  final concrete NVIDIA model identity. Incomplete/error streams are withheld.
- Eight-request, twelve-tool, two-revision and time/input/output bounds; one
  bounded JSON-format repair, no HTTP retry or different-provider fallback.
- GUI/CLI opt-in, objectives, real progress, report evidence and actual-change counts.
- Local/sample mode stays model-free. No new model provider or paid subscription.
- 112 application tests and 13/13 H-MEM checks passed. Live verification is
  recorded separately in `VERIFICATION.md`; scripted revision tests are labelled.
- Two live balanced reviews passed. A rain-objective run was withheld on an
  upstream error; complex-objective live adaptation remains unverified.

This is a prototype feature milestone. It does not establish competitive team
quality, a provider SLA or a completed hackathon submission.

## Demo 1 — 24 October 2026

Initial public source milestone; implementation and its first recorded
verification were completed on 23 October 2026. Git commit: `demo 1`. Tag: `demo-1`.

### Included

- Local GUI and CLI for building/reviewing six-member historical VGC teams from
  one to six locked favourites.
- Real public Dex/usage data, explicit sample mode and a local Zetaris SQL join.
- Schema-2 snapshot: 1,417 species/form records, 358 usage rows and 11,376
  independently set-validated options across 357 supported species/forms.
- Bounded contextual search with full-set deduplication and source-aware scoring.
- Independent team legality, remembered avoidance and refusal of invalid results.
- Actual stats, EV/nature explanations, conditional Speed, interaction checks,
  possible opening actions and four-of-six practice plans.
- Real Meterless H-MEM with pinned upstream source and conformance checks.
- Reports, Showdown export, run traces, progress and project-status GUI.
- Public setup, architecture, data, operations, development and milestone guides.
- A deliberately public sample generated with isolated temporary memory.

### Verified

73 application tests and 13/13 H-MEM conformance checks passed. Selected mechanics
were checked against Showdown arithmetic and running local simulator fixtures.
Local Zetaris reconstruction matched the sample, and the connected build and GUI
HTTP form/report/progress flow passed. Visual browser review is not claimed.

### Known limitations

Cloud model calls are disabled in the main product. Nightshift AI integration,
current-2026 rules, damage simulation, optimized IVs and opponent-specific solving
remain unfinished. No best-team, win-rate, production-readiness or complete
hackathon-eligibility claim is made. See the roadmap and verification notes.
